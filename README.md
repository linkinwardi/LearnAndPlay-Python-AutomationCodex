# The Automation Codex

A free, trilingual (EN / AR / FR) study course for *Automate the Boring Stuff with Python*,
with an 18-chapter syllabus, a 54-question final exam, and a downloadable Certificate of Completion.

This repository is the website, served via GitHub Pages.

## Files
- `index.html` — the entire course (single self-contained file)
- `app-ads.txt` — AdMob authorized-sellers file (required at the site root)
- `og-image.png` — social-share preview image
- `robots.txt`, `sitemap.xml` — SEO helpers
- `.nojekyll` — tells GitHub Pages to serve all files untouched

> Replace `automationcodex.com` in `index.html`, `robots.txt` and `sitemap.xml`
> with your real domain (or your GitHub Pages URL) for accurate SEO/canonical links.
